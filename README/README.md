# Student Attendance Management System (v0.1)

Ένα απλό και λειτουργικό πρόγραμμα σε Python για τη διαχείριση και παρακολούθηση απουσιών μαθητών με χρήση βάσης δεδομένων SQLite.

## Χαρακτηριστικά (Features)

* **Καταγραφή Απουσιών:** Δυνατότητα λήψης απουσιών για όλους τους εγγεγραμμένους μαθητές με ημερομηνία και ώρα (timestamp).
* **Συνολικές Απουσίες:** Αυτόματος υπολογισμός και ενημέρωση του συνολικού αριθμού απουσιών κάθε μαθητή.
* **Ιστορικό Log:** Προβολή πλήρους ιστορικού απουσιών συνδέοντας στοιχεία μαθητών (όνομα, τηλέφωνο) με την κατάσταση παρουσίας.
* **Διαχείριση Μαθητών:** Προσθήκη νέων μαθητών στο σύστημα.

---

## Προαπαιτούμενα (Requirements)

* **Python 3.x** εγκατεστημένη στον υπολογιστή σας.
* Δεν απαιτούνται εξωτερικές βιβλιοθήκες (χρησιμοποιούνται οι ενσωματωμένες βιβλιοθήκες `sqlite3` και `datetime`).
